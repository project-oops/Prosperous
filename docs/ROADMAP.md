# Roadmap

The intended order of work. Open work and defects are GitHub issues.

1. Save retargeting: reach `graft`, `graft::set_account` and `sfo::set` from both programs.
2. Progress reporting for a single large file transfer.
3. Read-back verification of a sent payload, comparing bytes from both ends.
4. The shell's `notify`, `browse`, `mount`, `sfoinfo` and `sfocreate` builtins as verbs.
5. Providers as configuration rather than code, per the capability layers in [DESIGN](DESIGN.md).
6. A media transfer section.
