| Feature / Screen | GUI View | CLI Counterpart | Documentation Page |

| **Logs** | Live Kernel Telemetry Streamer | `pros logs` | [logs.md](logs.md) |
| **Files** | Remote Storage Browser | `pros restore` | [files.md](files.md) |
| **Titles** | Title Supervisor & Launcher | `pros launch`, `pros close` | [titles.md](titles.md) |
| **Shell** | Remote Command Shell | `pros sh` | [shell.md](shell.md) |
| **Payloads** | Memory Payload Injector | `pros send` | [payloads.md](payloads.md) |
| **User Guide** | In-app Manual (`Help -> Docs`) | `pros --help` | [user-guide.md](user-guide.md) |

For higher-level instructions, see the [User Guide](user-guide.md).
